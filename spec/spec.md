# 「咳をしても一人じゃない」プロジェクト仕様書

## 1. 概要

### 1.1 アプリケーション説明

**「咳をしても一人じゃない」** は、匿名で咳を共有したり再生したりできるWebアプリケーションです。

## 2. 実装内容

### 2.1 対象コード

- `cough-app` 配下で Next.js (App Router), TypeScript を使用して実装する。

### 2.2 対象機能

| 機能 | 説明                                     |
| ---- | ---------------------------------------- |
| 録音 | ユーザーの咳を録音する。再録音も可能     |
| 投稿 | 録音されたデータをサーバーに送信して保存 |
| 再生 | 登録された咳を再生する                   |

## 3. 機能要件

### 3.1 録音

録音ボタンを表示し、必要ならマイクの使用を許可させて録音を開始する。咳であるかどうかの判定は一旦実装しない。長さ上限はとりま10秒。録音が終了したら再生し、再録音するか投稿するか選ぶ。

### 3.2 投稿

録音データを `coughs` フォルダにMP3形式で保存する。

### 3.3 再生

サーバーに登録された咳を再生ボタンと共に一覧表示する。再生ボタンを押したらデバイスの音量に従って再生する。
